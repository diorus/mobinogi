낚시 매크로

마비노기 모바일 PC 자동 낚시 · Windows 전용

⬇ fishing.exe 다운로드

파이썬 설치 없이 바로 실행 · 약 71MB · 모든 버전

사용법

  1. exe를 쓰기 가능한 폴더(바탕화면 등)에 둔다. 로그·설정이 exe 옆에 생긴다.
  2. 실행하면 UAC 창이 뜬다 → 예. 게임이 관리자 권한이라 매크로도 관리자여야 키가 들어간다.
  3. 첫 실행은 압축을 푸느라 몇 초 걸린다.
  4. Ctrl+Shift+F10 으로 어느 창에서든 시작/정지.

실행이 막히면

  • SmartScreen 경고: 추가 정보 → 실행
  • Windows Defender가 지우면: 보호 기록에서 허용하거나 폴더를 예외로 등록
